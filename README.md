# KeySeki（键迹）· 用户反馈

这里是 [KeySeki（键迹）](https://www.keyseki.com/) 的**反馈专用仓库**：只收集问题和建议，不包含代码。

KeySeki 是一个免费、无需注册的自适应打字训练网页应用。

## 怎么反馈

- 🐞 **遇到问题**：[提交问题报告](../../issues/new?template=bug.yml)
- 💡 **有想法/建议**：[提交建议](../../issues/new?template=idea.yml)
- 💬 **闲聊、提问、分享使用心得**：去 [Discussions](../../discussions)（如果已开启）

提交前先搜一下有没有人提过。

## 请注意

- 本仓库是公开的，**请不要在这里贴个人信息**。
- **请不要上传"导出存档"文件**：它含有你的练习内容和回放记录。需要时，我们会请你描述现象，或只贴其中一小段。
- 回复可能不及时，这是个人项目。

## English

This is the feedback-only repository for [KeySeki](https://www.keyseki.com/), a free typing trainer that needs no sign-up. It contains no source code. Please open an issue using the templates; don't post personal information or exported backup files here.
